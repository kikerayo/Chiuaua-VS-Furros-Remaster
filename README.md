19 aspectos, catálogo 3D, mapas infinitos, cinemáticas, drops, Chihuahua Maker y controles móviles con editor y modo patata.

En PC: WASD para moverte, Espacio para saltar, E para ladrar, Shift para dash, Q para cambiar objeto, F para usarlo y F5 para cambiar la cámara.

La versión 2V puede consultar el canal de actualizaciones desde Ajustes. Windows comprueba la integridad antes de instalar; Android pide la confirmación habitual del sistema.

APK ARM64 firmado, sin prueba física en teléfono. Multijugador pospuesto. YouTube en Android pendiente de servicio.
